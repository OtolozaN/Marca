# Sitio Web de Marca Personal - Óscar Toloza Navarro

Este repositorio contiene los archivos fuente para la página web de marca personal de **Óscar Toloza Navarro**, Comunicador Social Organizacional, Docente y Consultor en Comunicación y Marketing Digital.

## 📁 Estructura del Proyecto

```
/
├── index.html     # Estructura principal e interactividad HTML5
├── profile.jpg    # Foto oficial de perfil
├── styles.css     # Hoja de estilos CSS3 (Paleta clara con azules y acentos rojos)
├── script.js      # Lógica interactiva JS (Filtros, pestañas y scrollspy)
└── README.md      # Guía de publicación e instrucciones
```

## 🚀 Cómo publicar en GitHub Pages (Paso a Paso)

1. **Crear un nuevo repositorio en GitHub:**
   - Ve a [GitHub](https://github.com) e inicia sesión.
   - Haz clic en **New repository** (Nuevo repositorio).
   - Nómbralo por ejemplo: `marca-personal-oscar-toloza` o `<tu-usuario>.github.io`.
   - Marca el repositorio como **Public** y haz clic en **Create repository**.

2. **Subir los archivos:**
   - En la página principal de tu nuevo repositorio, haz clic en **"uploading an existing file"** (subir un archivo existente).
   - Arrastra o selecciona todos los archivos descomprimidos (`index.html`, `profile.jpg`, `styles.css`, `script.js`, `README.md`).
   - Haz clic en **Commit changes**.

3. **Activar GitHub Pages:**
   - Ve a la pestaña **Settings** (Configuración) de tu repositorio.
   - En el menú lateral izquierdo, haz clic en **Pages**.
   - En **Build and deployment > Source**, selecciona **Deploy from a branch**.
   - En **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
   - Haz clic en **Save**.

4. **¡Listo!** En 1 ó 2 minutos tu sitio web estará en línea en la URL proporcionada por GitHub (ej. `https://tu-usuario.github.io/marca-personal-oscar-toloza/`).
